# chinese-scenarios

可复现的中文学习场景、对话、发音和练习资产。

> **Status:** scaffold. The first content packs are being designed against `boxi-chinese/chinese-explain`.

Initial content packs:

- tones and pronunciation in meaningful context;
- word order, aspect, and meaning contrasts;
- dialogue repair and pragmatic fit.

Every scenario should include context, input, a learner task, expected observations, feedback criteria, a revision path, a transfer prompt, and an accessible text transcript. Characters, pinyin, tone marks, audio, and translation should use stable segment identifiers.
